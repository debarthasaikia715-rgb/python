# Simple Habit Tracker CLI

A minimalist, terminal-based habit tracker written in Python.  
No external dependencies • JSON storage • streaks + calendar view.

## Features

- Add new habits
- Mark daily completion (y/n)
- Current streak + longest streak calculation
- 30-day success rate
- Simple text calendar view (≈5 weeks)
- Data saved in `habits.json`
- No database / no fancy UI / no login required
