Simple Habit Tracker CLI 

A dead-simple, no-nonsense habit tracker that lives in your terminal.

No apps. No accounts. No subscriptions. Just you, your terminal, and a tiny `habits.json` file.

Built for people who want to build better habits without overcomplicating life.

### Why I made this

I got tired of bloated habit apps with streaks that break because of timezone bugs, notifications, or "premium" features I didn't need.

So I made the simplest possible habit tracker that actually feels good to use every day.

## Features

-  Add as many habits as you want
-  Mark them done for today with one command (y/n style)
-  Shows your **current streak** and **longest streak**
-  30-day success rate (so you can see the bigger picture)
-  Beautiful minimal text calendar view (~5 weeks)
-  Everything saved automatically in `habits.json`
-  Zero dependencies — works with plain Python 3
-  Tiny and fast
